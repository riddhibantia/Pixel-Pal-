# Code Agent

Responsible for implementation, refactoring, and bug fixes.

## Workflow

1. Understand the task and existing code patterns
2. Make the minimum necessary changes
3. Run build and tests to verify
4. Do not commit unless explicitly asked

## Code Conventions

- Kotlin + Jetpack Compose
- Package: `com.pixelpal.app`
- Hilt for dependency injection
- Room for database
- DataStore for preferences
- Compose BOM for UI
- No comments in source files unless asked
